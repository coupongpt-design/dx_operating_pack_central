[구글 메시지 다운로더 v4.5 사용설명서]

1. 프로그램 소개
   이 프로그램은 구글 메시지 웹(https://messages.google.com/web/)에 접속하여
   지정된 대상(이름, 전화번호)의 문자 내역과 이미지를 자동으로 다운로드합니다.

2. 준비 사항
   - 'targets.xlsm' 파일에 작업 대상 정보를 입력하세요.
     (필수: 이름, 전화번호 / 선택: 시작일, 종료일)
   - 인터넷이 연결되어 있어야 합니다.

3. 실행 방법
   - 'GoogleMsgDownloader.exe'를 실행하거나, python으로 실행할 수 있습니다.
     (예: python main_refactored.py)
   - 검은색 창(콘솔)이 뜨면 메뉴에서 "1. 작업 시작"을 선택하세요.

4. 초기 설정 (최초 1회)
   - 브라우저가 열리면 구글 메시지 웹 화면이 나옵니다.
   - 스마트폰의 메시지 앱 > 설정 > 기기 페어링 > QR 코드 스캐너를 켜세요.
   - 화면의 QR 코드를 찍어 로그인을 완료하세요.
   - 로그인이 완료되면 자동으로 작업이 시작됩니다.

5. 로그인 초기화 (Safe Mode)
   - 프로그램이 멈추거나 로그인 화면이 정상적으로 뜨지 않으면:
   - 메뉴에서 "2. 로그인 초기화"를 선택하세요.
   - 로그인 정보(프로필)가 초기화되며 다시 QR 스캔이 필요합니다.

6. 재작업이 필요할 때
   - 고객 폴더의 `작업완료.txt`를 삭제해도 스킵되는 경우가 있습니다.
   - `system_logs/job_tracker.db`에 완료 기록이 남아 있으면 자동 스킵됩니다.
   - 필요 시 job_tracker.db를 삭제하고 재실행하세요.

7. 주의 사항
   - 작업 중에는 브라우저 창을 끄거나 최소화하지 마세요. (가려지는 건 괜찮습니다)
   - 엑셀 파일(targets.xlsm)이 켜져 있으면 저장이 안 될 수 있으니 닫고 실행하세요.
