# 구글 메시지 다운로더 v5.1 - 사용 목적 상세 분석

## 🎯 핵심 목적

**B2C 서비스 사업자의 고객 상담 기록 자동 아카이빙 시스템**

이 프로그램은 구글 메시지 웹을 통해 다수의 고객과 주고받은 문자 메시지 내역을 **자동으로 수집·저장·문서화**하는 업무 자동화 도구입니다.

---

## 📌 주요 사용 시나리오

### 1. **여행사 / 숙박업 고객 관리**
폴더명 `customer_data`와 엑셀 내 키워드 강조 설정을 보면:
```python
"HIGHLIGHT_KEYWORDS": ["참석", "불참", "입금", "영수증", "트윈", "더블", "취소", "환불", "예약"]
```
- **여행사 패키지 상품 예약 관리**
- **호텔/펜션 객실 예약 관리**
- 입금 확인, 예약 변경, 취소/환불 요청 등의 민감한 키워드를 빨간색 굵은 글씨로 자동 강조

**예시 업무 흐름**:
1. 여행 상품 예약을 받으면서 고객과 문자로 소통
2. 예약 확정, 입금 확인, 일정 변경 등의 내역이 문자로 누적
3. 프로그램 실행 → 고객별로 전체 대화 내역을 엑셀 + 이미지로 자동 저장
4. 법적 분쟁 발생 시 증빙 자료로 활용

---

### 2. **고객 응대 품질 관리**
- **CS 담당자 교육용 자료**: 실제 고객 대화 내용을 분석하여 응대 품질 개선
- **컴플레인 관리**: 문제 발생 고객의 전체 대화 이력을 한눈에 파악
- **정기 감사**: 월별/분기별 고객 상담 내역을 아카이빙

---

### 3. **법적 증빙 자료 확보**
```python
# 검수보고서 자동 생성 (이미지 누락 여부 체크)
audit_df.to_csv(save_path / "검수보고서.csv", ...)
```
- 환불 분쟁, 예약 취소 클레임 등에서 **"말했다/안했다" 논쟁 방지**
- 모든 대화와 첨부 이미지(영수증, 신분증 등)를 완벽하게 보존
- 이미지 누락 여부를 자동 검수하여 데이터 무결성 보장

```python
targets = DataHandler.get_targets()
for idx, (name, phone, start_date, end_date) in enumerate(valid_list):
    # 각 고객별로 채팅방 진입 → 메시지 수집 → 엑셀 저장
```
- 수십~수백 명의 고객 데이터를 한 번에 처리
- 날짜 범위 필터링으로 특정 기간만 추출 가능

### 2. **브라우저 풀/세션 복제**
- 기본 프로필로 로그인 후 세션을 복제해 동일한 로그인 상태 유지
- 순차 처리 유지 + 컨텍스트 분리로 안정성 강화

### 3. **데이터 보존 전략**
```
customer_data/
├── 홍길동_01012345678/
│   ├── chat_log.xlsx          # 대화 내용 (이미지 임베딩)
│   ├── 검수보고서.csv           # 이미지 저장 성공/실패 로그
│   ├── 20230515_103020_img_1.jpg
│   ├── 20230516_141523_img_2.jpg
│   └── 작업완료.txt            # 중복 작업 방지 플래그
```
- **고객별 독립 폴더**: 각 고객의 데이터를 물리적으로 분리 저장
- **타임스탬프 파일명**: 날짜시간 기반 파일명으로 시간 순서 보장
- **작업완료 플래그**: 이미 처리된 고객은 자동 스킵 (재실행 시 효율성)

### 4. **엑셀 자동 서식**
```python
# 보낸 사람에 따라 배경색 자동 변경
fill_me = PatternFill(start_color="FFF2CC", ...)    # 나: 노란색
fill_other = PatternFill(start_color="E7E6E6", ...) # 상대: 회색

# 중요 키워드 자동 강조

    cell_content.font = font_bold_red  # 빨간색 굵게
```
- 카카오톡 스타일의 말풍선 효과 (배경색으로 발신자 구분)
- 예약/입금/취소 등 중요 단어를 시각적으로 강조
- 이미지를 엑셀에 직접 임베딩 (200px 높이로 리사이징)

### 5. **블랙박스 시스템** (디버깅)
```python
if CONFIG.get("USE_BLACKBOX", False):
    context.tracing.start(screenshots=True, snapshots=True, sources=True)
```
- 작업 실패 시 화면 녹화본을 자동 저장
- 문제 발생 지점을 스크린샷과 DOM 스냅샷으로 기록
- 개발자 없이도 문제 원인을 파악 가능

## 💼 상업적 가치 분석

### 1. **인건비 절감**
- **수작업 시**: 고객 1명당 10분 (복사/붙여넣기/이미지 저장)
- **자동화 후**: 고객 1명당 1~2분 (완전 자동)
- **100명 처리 기준**: 약 13시간 → 2시간 (약 **85% 시간 절감**)

### 2. **법적 리스크 제거**
- 환불 클레임 발생 시 즉시 증빙 자료 제시
- "입금 확인했다고 했잖아요" 등의 분쟁을 객관적 데이터로 해결
- 소송 비용 절감 및 브랜드 이미지 보호

### 3. **품질 관리 강화**
- 상담원의 응대 품질을 정량적으로 분석
- 우수 응대 사례를 교육 자료로 활용
- 고객 불만 패턴 분석을 통한 서비스 개선

## 🚀 실제 운영 방식

### **Daily 운영 케이스**
```
[오전 9시]
1. 어제 상담한 고객 10명의 정보를 targets.xlsm에 입력
2. 프로그램 실행 (QR 로그인은 최초 1회만)
3. 커피 마시면서 자동 처리 대기 (약 20분)
4. customer_data 폴더에서 결과 확인
5. 중요 고객 파일을 공유 드라이브에 백업
```

### **Monthly 감사 케이스**
```
[월말 정산]
1. 이번 달 전체 상담 고객 200명 리스트 작성
2. 시작일/종료일 설정 (2024-01-01 ~ 2024-01-31)
3. 프로그램 실행 → 자동 다운로드 (약 3~4시간)
4. 검수보고서.csv에서 이미지 누락 확인
5. 회계팀에 입금 증빙 자료 제출
```

## ⚠️ 제약 사항 및 한계

### 1. **구글 메시지 의존성**
- 구글 메시지 웹 UI가 변경되면 셀렉터 수정 필요
- 구글 정책 변경 시 접근 제한 가능성

### 2. **초기 설정 필요**
- QR 코드 스캔을 통한 로그인 (최초 1회)
- Playwright 브라우저 설치 필요

### 3. **처리 속도**
- 네트워크 속도에 의존적
- 이미지가 많은 대화는 처리 시간 증가
- 고객 1명당 평균 1~2분 소요
