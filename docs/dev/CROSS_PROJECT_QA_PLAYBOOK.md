# Cross-Project QA Playbook (Bridge)

이 경로는 프로젝트 내부의 기존 참조를 깨지 않기 위한 브리지다.

공용 canonical 문서는 아래로 이동했다.

- `dx_operating_pack/docs/CROSS_PROJECT_QA_PLAYBOOK.md`

이렇게 바꾼 이유:

- 신규 프로젝트가 DX Pack 설치/최신화만으로 공용 QA 운영 플레이북까지 함께 받게 하기 위함
- 공용/재사용 문서는 DX Pack 아래로, 프로젝트 전용 QA 문서는 `docs/dev/` 아래로 역할을 분리하기 위함

사용 기준:

- 다른 프로젝트에도 이식 가능한 QA 운영 원칙 -> `dx_operating_pack/docs/CROSS_PROJECT_QA_PLAYBOOK.md`
- 현재 프로젝트 전용 실사용 QA 기준 -> `docs/dev/REAL_WORLD_QA.md`
- 현재 프로젝트 사용자 여정/버그 루프 -> `docs/dev/USER_JOURNEYS.md`, `docs/dev/BUG_LOOP_PROTOCOL.md`
