autosum_copy2.exe usage

1. Put autosum_copy2.exe in the same folder as the target .xlsx and .pptx files.
2. Preferred filenames are:
   - 교통비 정리.xlsx
   - 교통비 정리.pptx
3. Run autosum_copy2.exe.
4. The result file is created as:
   - updated_presentation.pptx
5. A log file is also created:
   - debug_log.txt

If the preferred filenames are not present, the exe uses the first .xlsx and .pptx
file it finds in the same folder, excluding temporary files and updated_presentation.pptx.
