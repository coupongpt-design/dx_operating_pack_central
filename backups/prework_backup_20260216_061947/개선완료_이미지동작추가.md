### 2. ✅ 기본값 개선 (P1)

#### 개선: Timeout 기본값을 더 안전하게 변경

**Before:**
```python
self.spTimeout.setValue(int(step.timeout_ms))  # 0ms일 수 있음
```

**After:**
```python
# Set default to 5 seconds if not already set
timeout_value = int(step.timeout_ms) if step.timeout_ms > 0 else 5000
self.spTimeout.setValue(timeout_value)
```

**이유:**
- 초보 사용자가 0ms(무한 대기)를 설정하는 실수 방지
- 5초는 대부분의 경우에 적절한 값
- 경험 있는 사용자는 원하는 값으로 변경 가능
