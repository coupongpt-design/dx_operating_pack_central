# 🔍 기능 검토 보고서: "이미지 동작 추가" 버튼

**검토 날짜:** 2025-11-24  
**검토자 관점:** 프로그램 구매자 (최종 사용자)  
**대상 기능:** 이미지 동작 추가 버튼 (🖼️ Add Image)

---

## 📋 Executive Summary

구매자 관점에서 "이미지 동작 추가" 버튼의 전체 사용자 경험을 검토했습니다.  
이 기능은 매크로 프로그램의 핵심 기능으로, 사용자가 화면의 특정 이미지를 인식하고 클릭하는 동작을 추가할 수 있게 해줍니다.

**종합 평가:** ⭐⭐⭐⭐☆ (4/5)

---

## 🎯 기능 개요

### 기능의 목적
화면에서 특정 이미지를 찾아서 클릭하는 매크로 동작을 추가하는 기능입니다. 예를 들어:
- 게임의 특정 버튼 클릭
- 웹 페이지의 로그인 버튼 클릭
- 소프트웨어의 특정 아이콘 클릭

### 접근 방법
1. **툴바 버튼**: 상단 툴바의 🖼️ "Add Image" 버튼 클릭
2. **단축키**: 사용자 설정 가능한 핫키 (기본값: 없음, 설정 필요)

## 🔄 사용자 플로우 분석

### 단계 1: 버튼 클릭
```
사용자 액션: 툴바의 "Add Image" 버튼 클릭
└─> 코드 실행: main.py::add_image_step() (Line 766)
```

**✅ 긍정적 요소:**
- 버튼이 툴바에서 눈에 잘 띄는 위치에 있음
- 아이콘이 직관적 (🖼️)
- 툴팁으로 단축키 정보 제공

**⚠️ 개선 필요:**
- 버튼 클릭 후 즉각적인 피드백이 필요 (로딩 커서 등)

### 단계 2: 화면 캡처 및 ROI 선택
```
화면 캡처 → ROISelector 실행 → 사용자가 화면에서 영역 드래그
```

**코드 분석:**
```python
# main.py, Line 774-786
with mss.mss() as sct:
    mon = sct.monitors[0]
    # 전체 화면 캡처
    sct_img = sct.grab(monitor)
    img = np.array(sct_img)
    frame_bgr = cv2.cvtColor(img, cv2.COLOR_BGRA2BGR)
    
# ROI 선택 UI 표시
self.selector = ROISelector(frame_bgr, left, top, QSize(w, h))
self.selector.done.connect(self._on_roi_done)
```

**✅ 긍정적 요소:**
- 전체 화면을 캡처하여 어떤 영역이든 선택 가능
- ROISelector가 시각적으로 영역을 선택할 수 있게 함

**⚠️ 잠재적 문제:**
1. **멀티 모니터 환경**: `sct.monitors[0]`만 사용 → 첫 번째 모니터만 캡처됨
   - 구매자가 여러 모니터를 사용하면 다른 모니터의 이미지는 선택 불가
   
2. **캡처 순간의 타이밍**:
   - 버튼 클릭 순간의 화면을 캡처함
   - 사용자가 원하는 화면으로 전환할 시간이 없음
   
3. **에러 처리**:
   - 예외 발생 시 에러 메시지만 표시하고 종료
   - 재시도 옵션 없음

### 단계 3: 이미지 처리 및 대화상자 표시
```
ROI 선택 완료 → 이미지 인코딩 → ImageStepDialog 표시
```

**코드 분석:**
```python
# main.py, Line 793-823
def _on_roi_done(self, rect, crop_bgr, virt_info):
    # PNG로 인코딩
    _, buf = cv2.imencode(".png", crop_bgr)
    png_bytes = buf.tobytes()
    
    # 기본 StepData 생성
    step = StepData(
        id=str(uuid.uuid4())[:8],
        type='image_click',
        name='Image Click',
        png_bytes=png_bytes,
        threshold=0.8  # 기본값
    )
    
    # 설정 대화상자 표시
    dlg = ImageStepDialog(step, self)
    if dlg.exec_() == QDialog.Accepted:
        final_step = dlg.get_step_data()
        self.steps.append(final_step)
        self.add_list_item(final_step)
```

**✅ 긍정적 요소:**
- PNG 형식으로 인코딩하여 품질 유지
- 기본값이 합리적 (threshold=0.8)
- 대화상자가 모달로 표시되어 집중 가능

### 단계 4: ImageStepDialog 설정
**대화상자 구조** (dialogs.py, Line 84-246):

#### 📑 탭 1: Basic (기본 설정)
```
┌─────────────────────────────────┐
│ Step Name: [Image Click       ] │
│                                  │
│ Template: [미리보기 이미지      ] │
│           [Capture] [Load]       │
│                                  │
│ Action: [Click ▼]                │
│ Timeout: [0 ms]                  │
│ Confidence Threshold: [0.80]     │
└─────────────────────────────────┘
```

**✅ 긍정적 요소:**
- 직관적인 레이아웃
- 이미지 미리보기 제공
- "Capture Template" 버튼으로 이미지 재캡처 가능
- "Load Image" 버튼으로 파일에서 이미지 불러오기 가능

**⚠️ 개선 필요:**
1. **Timeout 기본값이 0ms**: 
   - 실제로는 무한 대기를 의미할 수 있지만 구매자 입장에서 헷갈림
   - 권장: 기본값 5000ms (5초) 정도로 설정
   
2. **Confidence Threshold 설명 부족**:
   - 0.0~1.0 범위의 의미 설명이 없음
   - 구매자가 어떤 값을 선택해야 할지 모름
   - 권장: 툴팁이나 도움말 추가

3. **Action 옵션의 의미**:
   - "Click", "Move Only", "None (Just Find)" 옵션이 있지만
   - 각 옵션이 무엇을 하는지 명확한 설명 없음

#### 📑 탭 2: Advanced (고급 설정)

**✅ 긍정적 요소:**
- 마우스 버튼 선택 가능 (left/right/middle/double)
- 클릭 전 대기 시간 설정 가능

**⚠️ 개선 필요:**
- 클릭 좌표 오프셋 설정 코드가 있지만 UI에 표시되지 않음

**✅ 긍정적 요소:**

   - 실시간으로 매칭 결과와 신뢰도 확인 가능
   - 구매자가 threshold 값을 조정하는 데 도움

2. **전처리 옵션 제공**:
   - Grayscale 변환으로 조명 변화에 강건하게
   - Blur로 노이즈 제거

**⚠️ 개선 필요:**
1. **Blur Kernel Size의 의미 불명확**:
   - 짝수/홀수 규칙 설명 없음
   - 권장값 안내 없음

2. **테스트 결과 해석 도움 부족**:
   - "conf=0.856"이 좋은 건지 나쁜 건지 판단 기준 없음

## 🐛 발견된 문제점

### 🔴 치명적 문제

#### 1. 멀티 모니터 미지원
**영향도:** 높음  
**재현 방법:**
1. 듀얼 모니터 환경에서 프로그램 실행
2. 이미지 동작 추가 버튼 클릭
3. 보조 모니터의 내용은 캡처되지 않음

**해결 방안:**
```python
# 제안 코드
with mss.mss() as sct:
    # 모든 모니터를 합친 가상 화면 캡처
    mon = sct.monitors[0]  # 전체 가상 화면
    # 또는 모니터 선택 UI 제공
```

#### 2. ImageStepDialog 반환값 누락
**코드 분석:**
```python
# dialogs.py, Line 233-245
def accept(self):
    # 설정값을 self._step에 저장
    self._step.name = self.edName.text()
    # ...
    super().accept()

# main.py, Line 814-817
dlg = ImageStepDialog(step, self)
if dlg.exec_() == QDialog.Accepted:
    final_step = dlg.get_step_data()  # ← 이 메서드가 없음!
```

**문제:** 
- `ImageStepDialog`에 `get_step_data()` 메서드가 정의되어 있지 않음
- 대신 `self._step`를 직접 수정하는 구조
- 일관성이 없어 혼란스러움 (NotImageDialog에는 있음)

**해결 방안:**
```python
# ImageStepDialog에 추가 필요
def get_step_data(self) -> StepData:
    return self._step
```
